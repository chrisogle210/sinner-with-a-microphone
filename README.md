# Sinner With a Microphone

**Grace Received. Grace Given.**

This is a static podcast-ministry website designed for free hosting on GitHub Pages. The original gritty podcast cover is included at `assets/original-podcast-cover.png`.

## Publish on GitHub Pages (no paid hosting)

1. Sign in to [GitHub](https://github.com/) and create a new **public** repository, for example `sinner-with-a-microphone`.
2. Upload **all files and the `assets` folder** from this package to the repository root. Commit the files to the `main` branch.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`; save.
5. GitHub will provide a URL such as `https://YOUR-USERNAME.github.io/sinner-with-a-microphone/` once publication completes.

The site uses relative asset paths and works when published as a repository site or under a custom domain. No build tools, API keys, or paid hosting are required.

## Before public ministry launch

- Replace illustrative episode material with recorded episodes and final approved show notes.
- Add verified downloadable PDF resources and a podcast player or hosting-platform episode URLs.
- Connect your own Buy Me a Coffee URL; the current button explicitly says **coming soon** and does not process payments.
- Decide whether to add a listener question form, and publish a privacy notice before collecting personal information.
- Review biblical content with a trusted pastor/mentor as appropriate.
- If collecting money, accurately identify the recipient and whether any gift is tax-deductible. The site currently makes no such claim.

## Updating

Edit `index.html`, commit, and GitHub Pages republishes automatically. The topic cards and their study text are in the page's `data` object near the bottom. Add new topics there and their matching cards in the question grid.

## Local preview

Open `index.html` in a browser, or serve the folder using a basic static web server. No installation required.
